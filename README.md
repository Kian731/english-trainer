# 英文學習 English Trainer（多益 TOEIC 導向）

一個免安裝、可離線使用的英文學習小軟體（純網頁）。

## 使用方式

直接用瀏覽器開啟 `index.html` 即可（雙擊檔案就好，不需要架伺服器）。
想傳給別人或放到網頁空間，用打包好的單一檔案 `english-trainer.html`。

## 內容規模

| 等級 | 對應多益 | 單字 | 文法重點 | Part 5 | Part 6 | Part 7 | 題目小計 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 基礎 | 350–500 | 200 | 46 | 202 | 100 | 100 | 402 |
| 進階 | 550–700 | 200 | 45 | 202 | 100 | 100 | 402 |
| 高級 | 750–900 | 200 | 45 | 202 | 100 | 100 | 402 |
| **合計** | | **600** | **136** | **606** | **300** | **300** | **1,206** |

Part 6 每級 25 篇短文（每篇 4 格）；Part 7 每級 28 組（單篇 20 組、雙篇 5 組、三篇 3 組）。

多益聽力閱讀測驗共 Part 1–7，其中 Part 1–4 為聽力，需要音檔與照片，本工具未涵蓋。

## 功能

- **單字卡**：多益高頻商務字彙，含音標、詞性、中文解釋、例句與翻譯；點卡片翻面，可標記「已學會」
- **語法**：每個重點含說明與商務情境例句，可標記「已讀」
- **模擬測驗**：可依 Part 分類練習
  - **Part 5 單句填空**：詞彙題約 72 / 詞性題 40 / 文法題約 89
  - **Part 6 段落填空**：商務短文挖 4 格，含多益特有的「整句插入」題
  - **Part 7 閱讀理解**：單篇、雙篇、三篇對照題，文章顯示在題目上方
  - 可單選一個 Part 練習，也可複選混合出題（至少要留一個）
  - Part 6/7 的同一篇文章題組會黏在一起出，不會被拆散重讀
  - 每回合可選 10 題、20 題或全部，可隨機抽題
  - 「優先出還沒答對過的題目」讓進度推得動，不會一直重複已會的題
  - 每回合會重新排列四個選項，正確答案不會固定在同一個位置
  - 作答後立即顯示對錯與中文解析，結束有成績、錯題回顧與最佳紀錄
- **首頁進度圓餅圖**：每個等級卡片上以三個空心圓餅圖顯示單字／語法／題目的完成百分比
- **學習者記錄**：可建立任意數量的獨立進度
  - 開啟頁面時**不會自動選人**，先顯示「請選擇您的進度」，未選擇前不顯示等級卡，避免誤用他人紀錄
  - 畫面一次只顯示目前這一位，右上角「切換學習者」展開清單挑選、新增或刪除
  - 名稱平常是純文字，按「修改名稱」才會變成輸入框，並有儲存／取消，避免手滑改到別人的名字
  - 「清除此學習者的進度」只清空這一位，不影響其他人
- **進度自動儲存**：存在瀏覽器 localStorage，關閉瀏覽器不會消失
  - 例外：無痕視窗、清除瀏覽資料、換瀏覽器或換電腦時不會保留
  - 舊版進度會在首次開啟時自動搬移，空白且未命名的舊欄位會被略過

## 檔案結構

```
index.html            介面結構
style.css             樣式
app.js                程式邏輯
data.js               等級設定與資料組裝
data/
  basic-words.js      基礎 200 單字
  basic-grammar.js    基礎 46 文法重點
  basic-quiz.js       基礎 Part 5（202 題）
  basic-part6.js      基礎 Part 6（8 篇 × 4 格）
  basic-part7.js      基礎 Part 7（8 組 / 30 題）
  inter-*.js          進階，結構同上
  adv-*.js            高級，結構同上
build-single.ps1      打包成單一檔案的腳本
english-trainer.html  打包產物（可單獨傳給別人）
```

## 如何新增內容

打開 `data/` 底下對應的檔案，依照現有格式往陣列裡加就好，程式會自動讀取，不用改任何邏輯。
新增整個檔案時，記得在 `index.html` 和 `build-single.ps1` 的清單裡加上它。

```js
// 單字
{ en: 'invoice', pos: 'n.', zh: '發票、請款單', phonetic: '/ˈɪn.vɔɪs/',
  example: 'Please pay the invoice before the end of the month.',
  exampleZh: '請在月底前支付這張請款單。' }

// 語法
{ title: '標題', point: '說明', examples: [{ en: '...', zh: '...' }] }

// 測驗題（answer 是正確選項的索引，從 0 開始）
// type：'vocab' 詞彙題 / 'form' 詞性題 / 'grammar' 文法題
{ type: 'vocab', question: 'Please pay the ____ before the end of the month.',
  options: ['invoice','employee','customer','department'], answer: 0,
  explain: 'pay the invoice＝支付請款單。' }
```

改完內容後，重跑打包腳本更新單一檔案版：

```
powershell -ExecutionPolicy Bypass -File .\build-single.ps1
```
